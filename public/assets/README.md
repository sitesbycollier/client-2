# Public assets folder

Use this folder for project-managed media files that should be served statically by Vite.

## Recommended structure

- `public/assets/images/` — photos, graphics, page-specific imagery
- `public/assets/icons/` — custom SVG or PNG icons
- `public/assets/docs/` — PDFs and downloadable files

## Usage in React components

Reference files from root-relative paths:

- `/assets/images/example.jpg`
- `/assets/icons/logo.svg`

## Notes

- Keep file names lowercase and kebab-case.
- Prefer optimized image sizes before uploading.
